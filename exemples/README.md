# exemples/

Fichiers d'essai et leurs témoins. Le cas canonique visé (premier jalon de
preuve) : un fichier ancré via OpenTimestamps, preuve complétée après
confirmation Bitcoin, témoin vérifié avec le client officiel `ots` —
l'outil de quelqu'un d'autre, pas le nôtre. Interopérabilité prouvée =
jalon atteint.
